ChatGPT (OpenAI)

  • ✅ Supported: No auth (not recommended)
  • ❌ Not supported: Bearer token
  • ✅ Supported: OAuth
    Redirect URI: https://chatgpt.com/connector_platform_oauth_redirect

INFO: About ChatGPT developer mode - ChatGPT developer mode is a beta feature that provides full Model Context Protocol (MCP) client support for all tools, both read and write.
(September 2025)

OpenAI - MCP - Risks and safety #

Custom MCP servers enable you to connect your ChatGPT workspace to external applications, which allows ChatGPT to access, send and receive data in these applications. Please note that custom MCP servers are not developed or verified by OpenAI, and are third-party services that are subject to their own terms and conditions.
OpenAI - Docs - MCP - Risks and safety

CRITICAL: OpenAI may transmit client metadata (which includes: userAgent, locale, userLocation, city, region, country, timezone, latitude, longitude, timezone_offset_minutes) when invoking tools.
SymbioMind does not condone OpenAI’s metadata transmission
and does not store or use this data.

ChatGPT’s MCP support exists, but behaves differently from the MCP spec and from other clients.

WARNING: User Experience - ChatGPT displays a consent dialog for each tool invocation. If your custom instructions trigger multiple memory retrieval calls, users will need to accept multiple popups before receiving a response to allow OpenAI to transmit client metadata (there is no opt out). This can interrupt conversation flow.

Prerequisites #

  • ChatGPT account (Plus, Team, Enterprise, or higher)
  • ChatGPT Developer Mode enabled (see Setup below)
  • MCP server running and accessible
  • OAuth configured if using authentication

Setup #

  1. Click on your Profile icon and select Settings

  2. Navigate to Apps → Advanced settings

  3. Toggle Developer Mode to ON, then click Create app

  4. Fill in your MCP server details:

    • Icon (Optional) - Upload an icon to represent your MCP server
    • Name - How this MCP server appears in ChatGPT (e.g., “My MCP”)
    • Description (Optional) - Personal note about what this server does
    • MCP Server URL - Full HTTPS URL (e.g., https://my.example.com/mcp)
    • Authentication - OAuth is recommended (use your OAuth Client ID and OAuth Client Secret)
    • I understand and want to continue - Check after reviewing OpenAI’s MCP risks and safety

  5. Click Create

    You’ll be redirected to your OAuth provider to authorize the connection.

  6. Verify connection and available tools:

    After successful authentication, ChatGPT will display your MCP server’s available tools. Make note of these tool names - you’ll use them to verify the connection is working during testing.

Testing #

  1. Start a new chat session

  2. Add the MCP server to this chat:

    • Click the [+] icon in the chat prompt area
    • Click "…more"
    • Select your MCP server from the list

    INFO: You must manually add the MCP server to EVERY new chat session, even though it’s configured globally in Settings.

  3. Verify tools are available:

    Ask: Do you have a list of tools available?

    ChatGPT should list your MCP server’s tools alongside its built-in capabilities. The tools should match what you saw during setup (see step 6 in Setup above).

  4. Test a tool invocation:

    Try calling one of your MCP server’s tools to confirm it’s working.

    WARNING: You’ll see a consent dialog for each tool call. Accept to proceed.

Client-specific usage, quirks and limitations #

WARNING: Tool output cannot be cited - ChatGPT cannot explicitly cite or reference MCP tool results in its responses. Memory retrievals happen invisibly without attribution.

CRITICAL: Projects Don’t Support MCP Tools

While you can appear to add MCP servers to Projects via the [+] button, the model cannot see or use these tools within Projects. MCP tools only work in regular chat conversations.

This is an OpenAI design limitation, not a MCP servers issue. Use regular chat instead of Projects for MCP functionality.

CRITICAL: OpenAI blocks write operations client-side

ChatGPT intercepts and blocks certain tool calls before they reach your MCP server based on heuristic classification. Tools with names like store_* or write_* may be blocked with “couldn’t determine safety status” errors, even if your MCP server explicitly allows them.

This is undocumented OpenAI behavior, not an MCP limitation.

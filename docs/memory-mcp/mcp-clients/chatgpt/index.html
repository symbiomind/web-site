ChatGPT (OpenAI)

  • ✅ Supported: No auth (not recommended)
  • ❌ Not supported: Bearer token
  • ✅ Supported: OAuth
    Redirect URI: https://chatgpt.com/connector_platform_oauth_redirect

NOTE: About ChatGPT develper mode - ChatGPT developer mode is a beta feature that provides full Model Context Protocol (MCP) client support for all tools, both read and write.
(September 2025)

OpenAI - MCP - Risks and safety #

Custom MCP servers enable you to connect your ChatGPT workspace to external applications, which allows ChatGPT to access, send and receive data in these applications. Please note that custom MCP servers are not developed or verified by OpenAI, and are third-party services that are subject to their own terms and conditions.
https://platform.openai.com/docs/mcp#risks-and-safety

NOTE: OpenAI may transmit client metadata (which includes: userAgent, locale, userLocation, city, region, country, timezone, latitude, longitude, timezone_offset_minutes) when invoking tools.
Memory MCP does not condone OpenAI’s metadata transmission
and does not store or use this data.

NOTE: User Experience - ChatGPT displays a consent dialog for each tool invocation. If your custom instructions trigger multiple memory retrieval calls, users will need to accept multiple popups before receiving a response to allow OpenAI to transmit client metadata (there is no opt out). This can interrupt conversation flow.
